# DisplayToggle

[English](README.en.md)

外付けモニターを、ケーブルを抜かずに macOS から切り離したり、戻したりできるメニューバーアプリです。同じことができるコマンド `displayctl` も付いています。

モニターの電源を切るだけだと、macOS はしばらくそのモニターがつながっているものとして扱うので、カーソルやウインドウが真っ暗な画面に移ってしまいます。DisplayToggle で切り離すと、macOS からすぐに消えます。

- macOS 13 以降で動きます（Apple シリコン・Intel）。ただし、Intel の Mac での切り離しはまだ試せていません。
- 日本語と英語に対応しています。アプリもコマンドも、Mac の言語設定に合わせて切り替わります。

## ダウンロードと入れ方

[Releases](https://github.com/guribow/display-toggle/releases/latest) から zip をダウンロードしてください。`DisplayToggle-<版>-ja.zip` には日本語の説明書、`-en.zip` には英語の説明書が入っています。アプリはどちらも同じです。

1. zip を開き、DisplayToggle.app を「アプリケーション」フォルダへ移します。
2. ダブルクリックすると「開けませんでした」という警告が出るので、「完了」で閉じます。App Store 以外のアプリなので、最初の 1 回だけ出ます。
3. システム設定の「プライバシーとセキュリティ」を開き、下のほうにある「このまま開く」を押してパスワードを入れます。
4. もう一度ダブルクリックして、「開く」を押します。

メニューバーに画面のアイコンが出たら準備完了です。新しい版に入れ替えたときは、2〜4 をもう一度行ってください。

## 使い方

- メニューバーのアイコンを押すと、外付けモニターが並びます。
- モニター名を押すと、切り離す・戻すが切り替わります。✓ が付いているのが使用中です。
- メインのモニターと、1 台しかないモニターは切り離せません。
- 同じ型番のモニターが 2 台あるときは、「(1)」「(2)」を付けて区別します。
- 切り離したままケーブルを抜くと、「（ケーブル未接続）」と表示されます。つなぎ直せば元に戻ります。もう使わないときは、押すと一覧から消えます。
- ログアウトや再起動をしたとき、アプリを終了したときは、切り離したモニターが元に戻ります。

## ターミナルで使う（使わなければ不要）

zip に入っている `displayctl` で、同じことをターミナルから行えます。zip を開いたフォルダで次を実行すると使えるようになります。

```bash
xattr -d com.apple.quarantine displayctl
sudo mkdir -p /usr/local/bin && sudo cp displayctl /usr/local/bin/
```

```bash
displayctl list            # モニターの一覧
displayctl off 名前        # 切り離す（名前の一部、「(2)」付きの名前、一覧の番号のどれかで指定）
displayctl on [名前]       # 戻す（名前を省くとすべて）
displayctl toggle 名前     # 切り離す・戻すを切り替える
displayctl forget 名前     # ケーブル未接続のモニターを一覧から消す
```

## 困ったとき

- **切り離したモニターが戻らない**：`displayctl on` を実行してください。それでも戻らないときは、アプリを終了するか、ログアウトしてください。
- **「ログイン時に起動」でエラーが出る**：システム設定の「一般」→「ログイン項目」に、DisplayToggle を手で追加してください。

## 気をつけること

- macOS の非公開の機能（`CGSConfigureDisplayEnabled`）を使っているので、macOS のアップデートで動かなくなることがあります。
- データを外部に送ることはありません。

## 消し方

1. メニューバーのアイコン →「終了」（切り離したモニターは元に戻ります）
2. DisplayToggle.app をゴミ箱に入れます。
3. 記録も消すときは、`~/Library/Application Support/displayctl` をゴミ箱に入れます。
4. `displayctl` を入れたときは、`sudo rm /usr/local/bin/displayctl` を実行します。

## ソースからビルドする

Xcode（swiftc）が必要です。

```bash
./build.sh   # アプリと displayctl をビルドして入れる
./dist.sh    # dist/ に配布用の zip を作る
```
